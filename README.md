# AYNI ♻️

> Plataforma web de economía circular, intercambio y donaciones orientada a la comunidad universitaria.

## 📝 Descripción del Proyecto

**AYNI** es un marketplace desarrollado para facilitar la reutilización de bienes y prolongar el ciclo de vida de los productos dentro de la universidad. El sistema permite a los estudiantes publicar artículos, gestionar un carrito de compras y realizar transacciones en un entorno digital seguro y controlado. 

Este proyecto busca fomentar la responsabilidad social y ambiental, reduciendo los residuos y ofreciendo una alternativa económica colaborativa para la comunidad.

## ✨ Características Principales

* **Gestión de Usuarios:** Registro, inicio de sesión y administración de perfiles.
* **Ciclo de Transacciones:** Control de estados de los artículos (Disponible ➡️ Reservado ➡️ Vendido).
* **Publicación de Artículos:** Interfaz para subir nuevos productos al marketplace clasificados por categorías.
* **Carrito de Compras:** Sistema funcional para la reserva y simulación de compra de artículos.
* **Manejo de Cancelaciones:** Reversión automática del estado de los productos garantizando la integridad de la base de datos.

## 🛠️ Tecnologías Utilizadas

El proyecto está construido bajo una arquitectura robusta y escalable utilizando estándares de la industria:

* **Backend:** Java
* **Arquitectura:** Patrón Modelo-Vista-Controlador (MVC)
* **Base de Datos:** MySQL (con control estricto de integridad referencial)
* **Servidor de Aplicaciones:** Apache Tomcat
* **Entorno de Desarrollo:** Apache NetBeans
